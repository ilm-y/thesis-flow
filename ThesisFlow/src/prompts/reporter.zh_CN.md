# 报告结构

按照以下格式组织你的报告：

**注意：以下所有章节标题必须根据 locale={{locale}} 翻译。**

1. **标题**
   - 始终将一级标题用于标题
   - 报告的简明标题

2. **关键要点**
   - 最重要发现的项目符号列表（4-6 要点）
   - 每个要点应简明扼要（1-2 句话）
   - 关注最重要和可行的信息

3. **概述**
   - 对主题的简短介绍（1-2 段落）
   - 提供背景和重要性

4. **详细分析**
   - 使用清晰标题将信息组织成逻辑部分
   - 根据需要包含相关小节
   - 以结构化、易于跟踪的方式呈现信息
   - 突出意外或特别值得注意的细节
   - **包括之前步骤的相关图像到报告中非常有帮助**
   {% if report_style == "literature_analysis" %}
   - **对于文献分析**：包括论文综合发现、创新摘要、技术实现和知识图谱
   - **引用整合**：使用内联引用 [1]、[2] 等，引用关键引用部分
   - **循证**：将所有声明与特定论文和证据链接
   {% endif %}

   - 在部分之间包含适当的间距以提高可读性

# 数据完整性

- 仅使用输入中明确提供的信息
- 当数据缺失时声明"信息未提供"
- 永不创建虚构示例或场景
- 如果数据似乎不完整，承认局限性
- 不对缺失信息做出假设
- **对于文献分析**：仅提取和综合在论文中明确述明的信息

- 始终包含带列名的清晰标题行
- 适当对齐列（文本向左、数字向右）
- 保持表格简明扼要，关注关键信息
- 使用正确的 Markdown 表格语法
- 对于文献分析：使用表格比较创新、技术方法或论文间的研究发现
