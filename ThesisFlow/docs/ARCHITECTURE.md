## 🔄 完整处理流程

```
┌─────────────────────────┐
│  研究任务输入           │
│  (Research Description) │
│                         │
│ "Search for AI glass... │
│  timeline, current...   │
│  market situation..."   │
└────────────┬────────────┘
             │
             ▼
    ┌────────────────────────────────────────────┐
    │  1️⃣  查询优化 STEP                          │
    │  optimize_search_queries()                 │
    │                                            │
    │  输入: 冗长的自然语言描述                  │
    │  处理:                                     │
    │    • 正则表达式关键词提取                 │
    │    • 分类关键词 (域名/技术/应用/时间)   │
    │    • 生成多个查询组合                     │
    │  输出: 3-5 个精确的布尔查询               │
    │                                            │
    │  示例输出:                                 │
    │  ├─ "smart glasses" OR "AR glasses" AND vision
    │  ├─ "head-mounted display" AND apps AND 2020-2025
    │  ├─ "wearable display" AND optical design
    │  └─ ...                                    │
    └────────────┬────────────────────────────────┘
                 │
                 ▼
    ┌────────────────────────────────────────────┐
    │  2️⃣  执行搜索 STEP                          │
    │  web_search() × N                          │
    │                                            │
    │  输入: 优化后的查询                        │
    │  处理:                                     │
    │    • 对每个查询执行搜索                   │
    │    • 从 arXiv/IEEE/ACM 获取结果           │
    │    • 合并所有结果                         │
    │  输出: 300-500 个搜索结果                  │
    │                                            │
    │  示例结果:                                 │
    │  ├─ Paper 1 (arxiv.org/abs/2024.xxxxx)
    │  ├─ Paper 2 (ieee.org/publication/xxxxx)
    │  ├─ Paper 1 (重复) ✓ 标记
    │  ├─ Error Page (404) ✓ 标记
    │  └─ ... 295 more                          │
    └────────────┬────────────────────────────────┘
                 │
                 ▼
    ┌────────────────────────────────────────────┐
    │  3️⃣  结果过滤 STEP                          │
    │  filter_and_rank_results()                 │
    │                                            │
    │  输入: 300-500 个搜索结果                  │
    │  处理:                                     │
    │    Phase 1: 去重 (URL/标题)               │
    │      ├─ 去除 25 个重复结果                │
    │      └─ 保留 275 个                        │
    │                                            │
    │    Phase 2: 质量检查                       │
    │      ├─ 检查损坏链接 (404, Error)        │
    │      ├─ 检查垃圾内容                     │
    │      └─ 去除 220 个低质量结果             │
    │         保留 55 个                         │
    │                                            │
    │    Phase 3: 相关性评分 (0-1)              │
    │      ├─ 关键词匹配数                     │
    │      └─ 关键词匹配率                     │
    │                                            │
    │    Phase 4: 质量评分 (0-1)                │
    │      ├─ 学术来源奖励                     │
    │      ├─ 内容深度                         │
    │      └─ 发表日期                         │
    │                                            │
    │    Phase 5: 综合排序                       │
    │      └─ Score = Relevance(60%) + Quality(40%)
    │                                            │
    │    Phase 6: 阈值过滤                       │
    │      └─ 保留 Score > 0.25 的结果        │
    │         最终保留 15-20 个结果              │
    │                                            │
    │  输出: 15-20 个高质量、去重、排序结果    │
    │                                            │
    │  按排名展示:                               │
    │  ├─ #1 Vision Transformers... [Score: 0.92]
    │  ├─ #2 CNN Architecture Review... [0.85]
    │  ├─ #3 Deep Learning Survey... [0.78]
    │  └─ ... (filtered & ranked)               │
    └────────────┬────────────────────────────────┘
                 │
                 ▼
    ┌────────────────────────────────────────────┐
    │  4️⃣  质量评分 STEP (可选)                  │
    │  assess_paper_quality()                    │
    │                                            │
    │  输入: 15-20 个过滤后的结果                │
    │  处理: 基于 6 个维度评分 (0-100)          │
    │                                            │
    │    维度 1: 近期性 (15%)                    │
    │    ├─ 0-2 年: 100 分                      │
    │    ├─ 2-5 年: 80 分                       │
    │    └─ >10 年: 20 分                       │
    │                                            │
    │    维度 2: 引用数 (20%)                    │
    │    ├─ 1000+: 100 分                       │
    │    ├─ 100-1000: 80 分                     │
    │    └─ <10: 30 分                          │
    │                                            │
    │    维度 3: 发表地 (20%)                    │
    │    ├─ arXiv/IEEE/ACM: 100 分              │
    │    ├─ Springer/Journal: 80 分             │
    │    └─ Blog: 40 分                         │
    │                                            │
    │    维度 4: 内容深度 (15%)                  │
    │    ├─ >500 字: 100 分                     │
    │    └─ <50 字: 20 分                       │
    │                                            │
    │    维度 5: 方法清晰度 (15%)                │
    │    ├─ 清晰: 100 分                        │
    │    └─ 不清楚: 低分                        │
    │                                            │
    │    维度 6: 相关性 (15%)                    │
    │    ├─ 100% 关键词: 100 分                 │
    │    └─ 50% 关键词: 50 分                   │
    │                                            │
    │    综合分数 = Σ(维度分数 × 权重)         │
    │                                            │
    │  输出: 按质量分数排序的论文 + 星级评级   │
    │                                            │
    │  质量分级:                                 │
    │  ├─ ★★★★★ (90-100): 2 篇 - 顶级论文
    │  ├─ ★★★★☆ (75-90): 5 篇 - 高质量
    │  ├─ ★★★☆☆ (60-75): 4 篇 - 中等
    │  ├─ ★★☆☆☆ (45-60): 2 篇 - 基础
    │  └─ ★☆☆☆☆ (<45): 1 篇 - 可能排除
    └────────────┬────────────────────────────────┘
                 │
                 ▼
    ┌────────────────────────────────────────────┐
    │  ✅ 最终使用                               │
    │                                            │
    │  优先级别 1 (质量分数 >80):                │
    │  └─ 用于主要论点和重要讨论                │
    │                                            │
    │  优先级别 2 (质量分数 60-80):              │
    │  └─ 用于背景和支持论点                    │
    │                                            │
    │  优先级别 3 (质量分数 <60):                │
    │  └─ 用于简要提及或引用                    │
    └────────────────────────────────────────────┘
```
