ARCHITECTURE COMPONENTS
================================================================================

Coordinator Layer:
  - 自动任务分类 (Traditional vs Deep-Mining)
  - 用户澄清和范围界定
  - 工作流路由

Planner Layer:
  - 传统: 单层研究计划
  - 深度分析: 3层分析计划
    Layer 1: 论文收集 (paper_analysis)
    Layer 2: 结构化提取 (citation_network)
    Layer 3: 综合分析 (technical_breakdown)

Researcher Layer:
  - 工具选择器: 根据 analysis_type 选择工具
  - 5 个专用工具 + 通用工具
  - 并行执行支持

Reporter Layer:
  - 输出格式自适应
  - 深度分析: 学术报告格式
  - 传统: 综合研究报告格式
  - 创新图谱集成

DATA STRUCTURES
================================================================================

新增 Pydantic 模型:

PaperMetadata:
  - 标题, 作者, 出版年份, 场地
  - 摘要, 关键词, 研究领域
  - 方法论, 主要贡献, 数据集
  - 限制, 未来工作

CitationAnalysis:
  - 总引用数, 引用列表
  - 引用网络, 关键作者
  - 研究基础, 相关论文
  - 新颖性评估

TechnicalBreakdown:
  - 问题陈述, 解决方案
  - 技术组件列表
  - 数学基础, 实验设置
  - 结果摘要, 性能指标
  - 实现指导

InnovationNode:
  - 创新标题和描述
  - 技术新颖性, 应用领域
  - 先决条件, 限制
  - 未来潜力

KNOWN LIMITATIONS & PLACEHOLDERS

  2. citation_analysis - 返回示例格式，需集成数据库 API
  3. technical_breakdown - 返回示例格式，需 NLP 模型

  - 学术 API: Semantic Scholar, CrossRef, CORE
  - NLP 模型: spaCy, transformer models
  - 知识图谱: Neo4j, RDF 库
